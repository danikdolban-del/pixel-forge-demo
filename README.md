# Pixel Forge

Демонстрационный магазин игровых компьютеров и ноутбуков с каталогом, заявками и закрытой админкой.

## Запуск в Windows PowerShell

Нужен Node.js 22 или новее.

1. Установите зависимости командой pnpm install.
2. Скопируйте настройки командой Copy-Item .env.example .env.
3. Запустите pnpm dev.
4. Откройте http://localhost:5173.

API запускается отдельно на http://localhost:3001.

Демо-вход в админку: http://localhost:5173/admin

- Логин: admin
- Пароль: PixelForgeDemo2026!

Значения берутся из файла .env. Поменяйте пароль и SESSION_SECRET, если будете публиковать приложение.

## Данные

Каталог и заявки хранятся в SQLite-файле data/pixel-forge.sqlite. При первом запуске база заполняется восемью демонстрационными товарами. Заявки доступны в админке на вкладке «Заявки». Удаление товара не удаляет ранее поступившие заявки: в них сохраняется название товара.

## Сборка

После pnpm build запускайте приложение командой pnpm start.

Витрина, товары и цены созданы для демонстрации. Главное изображение хранится в `public/images`; фотографии товаров загружаются с Unsplash. Если фотография товара недоступна, карточка показывает встроенную заглушку.
